# ADR-014 — Quati-issued JWT access tokens, OIDC for humans, token exchange for agents

**Status:** Accepted (2026-11-15, owner authorization of implementation; specification v8.1). **Related:** RFC-013 §3–§5.

## Context
Humans, Quati's own agents, installed capabilities, channel adapters and remote agents (A2A/MCP)
need verifiable identity with short-lived, narrowly scoped, revocable credentials. Credentials must
never reach model context.

## Alternatives considered
- **Opaque session tokens with a database lookup on every call.** Simple revocation, but every hop
  (worker, capability subprocess, remote agent) needs database access to the token store, and it
  does not interoperate with A2A/OAuth peers. Rejected as the primary mechanism; refresh tokens stay opaque.
- **Forward the IdP's own tokens everywhere.** This couples every component to one IdP, provides no
  local profile and widens blast radius (an IdP token is typically valid for many audiences). Rejected.
- **PASETO v4.public.** Sound, but A2A, MCP authorization and enterprise gateways expect OAuth/JWT.
  Rejected for interoperability.
- **Macaroons/biscuits.** Elegant attenuation, small ecosystem. Deferred.
- **Chosen:** Quati is its own token issuer.
  - Access tokens are JWS JWTs signed with EdDSA/Ed25519, with a 10-minute human / ≤5-minute
    delegated lifetime.
  - Refresh tokens are opaque, hashed and rotating, with reuse detection.
  - Humans authenticate with `local-os` (LOCAL) or OIDC Device Authorization Grant, RFC 8628 (SERVER).
  - Agents and services authenticate with `private_key_jwt` (RFC 7523).
  - Delegation and agent-to-agent calls use OAuth 2.0 Token Exchange (RFC 8693) with the `act` claim.

## Decision
The chosen option above. Library choice is adapter-only:
- `PyJWT` with `cryptography` for JWS/JWKS, or `joserfc`; pick one in the S00 TRD update.
- `authlib` for the OIDC device flow (S05).
- `keyring` for the local device and issuer keys.

## Consequences
- Revocation is "short expiry + revocation set checked on write and dispatch". Reads may lag
  revocation by ≤ 10 minutes, but membership changes are immediate because grants are not in tokens.
- Key rotation: the issuer publishes ≥ 2 keys (`kid`), rotates every 90 days in SERVER, and holds a
  single key in LOCAL that rotates on `quati doctor --rotate-keys`.
- Clock skew tolerance is 60 s. A host with a wrong clock fails closed and `doctor` reports it.
