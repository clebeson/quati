# ADR-006 — Weak model support by calibrated roles

**Status:** Accepted for specification v8, pending implementation validation.

## Context
Quati must provide a local-first professional secretary with a modular provider ecosystem, but prior specs were too broad and tended to confuse documentation with implementation proof.

## Decision
Small models for social/simple/low-risk routing, strong models as policy-driven fallback.

## Rationale
Practical cost and latency without assuming model equivalence.

## Consequences and constraints
No fixed model identity or benchmark claims without running tests. Implementers MUST audit this decision against observed evidence before changing it; exceptions require a new ADR and affected test updates.

## Verification
In the owning slice, demonstrate one positive observable behavior, a representative failure/negative case and evidence grade. No implementation conclusion is asserted here.
