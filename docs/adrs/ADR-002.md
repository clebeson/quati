# ADR-002 — SCS outcomes are provider-neutral

**Status:** Accepted for specification v8, pending implementation validation.

## Context
SECMA must provide a local-first professional secretary with a modular provider ecosystem, but prior specs were too broad and tended to confuse documentation with implementation proof.

## Decision
SCS definitions are portable; Pydantic AI deferred capabilities are an implementation mapping.

## Rationale
Reuse existing framework discovery while protecting business outcome semantics.

## Consequences and constraints
No requirement to build independent capability orchestration server initially. Implementers MUST audit this decision against observed evidence before changing it; exceptions require a new ADR and affected test updates.

## Verification
In the owning slice, demonstrate one positive observable behavior, a representative failure/negative case and evidence grade. No implementation conclusion is asserted here.
