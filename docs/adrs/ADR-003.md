# ADR-003 — DBOS now, Temporal as a deferred port

**Status:** Superseded by ADR-015.

Superseded: DBOS is not used in v8.1; see ADR-015 (ledger-driven worker, SQLite/PostgreSQL LedgerPort). The text below is kept for history.

## Context
Quati must provide a local-first professional secretary with a modular provider ecosystem, but prior specs were too broad and tended to confuse documentation with implementation proof.

## Decision
Use DBOS for workflows with PostgreSQL business ledger; implement minimal DurableRunner interface.

## Rationale
Lower operational overhead in local-first setting while retaining future possibility of migration.

## Consequences and constraints
Engine history is not portable, migration involves new adapter and workflow drain. Implementers MUST audit this decision against observed evidence before changing it; exceptions require a new ADR and affected test updates.

## Verification
In the owning slice, demonstrate one positive observable behavior, a representative failure/negative case and evidence grade. No implementation conclusion is asserted here.
