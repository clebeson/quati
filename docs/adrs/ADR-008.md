# ADR-008 — Evidence-based acceptance gates

**Status:** Accepted for specification v8, pending implementation validation.

## Context
Quati must provide a local-first professional secretary with a modular provider ecosystem, but prior specs were too broad and tended to confuse documentation with implementation proof.

## Decision
L0 static/L1 unit/L2 integration/L3 real LLM/L4 authorized external/L5 operational evidence tiers.

## Rationale
Prevents simulated tool calls from masquerading as real autonomous discovery.

## Consequences and constraints
No unbounded test volume; one discriminating case per risk branch. Implementers MUST audit this decision against observed evidence before changing it; exceptions require a new ADR and affected test updates.

## Verification
In the owning slice, demonstrate one positive observable behavior, a representative failure/negative case and evidence grade. No implementation conclusion is asserted here.
