# ADR-005 — Trusted prompt compiler and constrained agent proposals

**Status:** Accepted for specification v8, pending implementation validation.

## Context
SECMA must provide a local-first professional secretary with a modular provider ecosystem, but prior specs were too broad and tended to confuse documentation with implementation proof.

## Decision
Operator/profile config compiled deterministically; LLM modifications staged, evaluated and promoted separately.

## Rationale
Separates “what model is asked” from “what system will allow”.

## Consequences and constraints
No arbitrary generated Python guards or policy evaluator in YAML. Implementers MUST audit this decision against observed evidence before changing it; exceptions require a new ADR and affected test updates.

## Verification
In the owning slice, demonstrate one positive observable behavior, a representative failure/negative case and evidence grade. No implementation conclusion is asserted here.
