# ADR-004 — Deterministic control statechart, agentic execution

**Status:** Accepted for specification v8, pending implementation validation.

## Context
Quati must provide a local-first professional secretary with a modular provider ecosystem, but prior specs were too broad and tended to confuse documentation with implementation proof.

## Decision
Use pure reducer/validated YAML for commitment control; specialist engines choose internal graphs.

## Rationale
Makes success/failure and allowed transitions enforceable without limiting reasoning.

## Consequences and constraints
Do not require LangGraph or a state-machine library for every skill. Implementers MUST audit this decision against observed evidence before changing it; exceptions require a new ADR and affected test updates.

## Verification
In the owning slice, demonstrate one positive observable behavior, a representative failure/negative case and evidence grade. No implementation conclusion is asserted here.
