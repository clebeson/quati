# Quati — Executive Overview (English)

**The product:** an AI executive secretary that knows when to speak, ask, investigate, delegate, wait and deliver. Its real value is the management of professional commitments and communication, not a fashionable inventory of agents.

**First demonstration:** user asks for a PRD; Quati accepts one durable commitment, researches permitted documents, asks only for decisive missing facts, handles changes midway, reports meaningful progress and returns a concise evidence-based summary plus a versioned document. The underlying harness can be swapped without losing the relationship.

**Architecture:** portable SCS outcome contracts; Pydantic AI runtime to load tools and capabilities; a Behavior Package Compiler producing validated prompts and control statecharts; small-model context engineering; a SQLite-first commitment ledger with a ledger-driven worker (PostgreSQL backend contract-tested) for durable responsibility; adapters to any approved models, harnesses, skills, MCPs, A2A agents and brains.

**Key commercial quality gates:** no fabricated work completion, no lost commitments under specified faults, no unauthorized cross-tenant effects, autonomous model tool choice demonstrated by sealed holdout, and measurable interaction value versus directly using a specialist agent CLI.

**Implementation approach:** lightweight headless Python first. Only eight bounded vertical slices; each slice has observable outcomes and red-team evidence. No UI until the professional-secretary behavior is proven.
