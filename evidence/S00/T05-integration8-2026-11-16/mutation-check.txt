Explanations of the survivors in A:
* S02b (one NFKC, before the casefold only). Equivalent in outcome. Exhaustive computation over every Unicode
  code point: exactly 26 code points fold differently under the mutant (U+01F0, U+0390, U+03B0, U+1E96-U+1E99,
  U+1F50, U+1F52, U+1F54, U+1F56, U+1FB6, U+1FB7, U+1FC6, U+1FC7, U+1FD2, U+1FD3, U+1FD6, U+1FD7, U+1FE2-U+1FE4,
  U+1FE6, U+1FE7, U+1FF6, U+1FF7). In both forms the result holds a letter that occurs in no table word
  (a Greek letter, or j, h, t, w, y carrying a combining mark that neither form removes), so the text is not
  social under either. No code point has a casefold that starts with a combining mark while its NFKC form does
  not, so the second NFKC can never compose a table letter across a character boundary.
* S12 (a phrase belongs to the last language that lists it). Equivalent on the specified table: no phrase is
  listed twice (tests/unit/test_s00_integration8.py::test_e_the_social_table_is_exactly_the_english_and_portuguese_entries
  pins `len(PHRASES) == number of listed entries`), so first-wins and last-wins build the same mapping. The rule
  matters only if a later table change adds a duplicate; that change must add its test.
* S15 (shortest phrase first). Equivalent on the specified table. Exhaustive computation over all 230513 sequences
  of one to three entries (table phrases, urgency phrases, markers; at most 12 words): none has more than one
  segmentation, so the order in which phrase lengths are tried cannot change the entries found or the reply.

  by another one and the lookup is by equality, so removing one changes no answer: the audit's own verdict

  are KILLED by test_t03_t11_a_receipt_whose_request_id_has_another_shape_is_never_found.
* X07 (the presentation boundary without the shared exit rule) and, in table B, X06 (the ask use case without it).
  The rule is applied twice by design, once in the use case and once at the boundary, so that the two cannot
